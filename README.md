# 黎凡特讀者導覽

小說《黎凡特》的讀者導覽網站，以 GitHub Pages 發布。

- 網址：https://rosatya.github.io/levant-guide/
- 內容全部在 `index.html`，地圖圖檔是 `map-sketch.jpg`。

## 維護

- 小修改（錯字、勘誤）：在 GitHub 網頁上開啟 `index.html`，按鉛筆圖示編輯，存檔（Commit changes）後一兩分鐘內網站會更新。
- 勘誤與更新紀錄在「07 勘誤與更新」區塊，每次修改請在更新紀錄加一行日期與說明。
- 名詞速查的資料在檔案後段的 `G` 陣列，每一列格式為 `[名詞, 分類, 所屬, 首次出現章節編號, 短說明, 長說明]`。
